# 英歌舞数字博物馆线上正式版

本目录直接依据服务器在 2026-09-04 的实际运行状态整理，不再依赖“合集”目录。

## 版本来源

- 公众网站与英歌小槌：服务器统一 release `20260907-voice8`
- 正式域名：`https://yinggemus.cn/`
- 备案号：`粤ICP备2026130280号-2`
- 语音引擎：浏览器实时识别优先，本地 Sherpa-ONNX ASR、唤醒词与 TTS 作为后备

网站与智能体已在服务器上合并为同一个正式 release，服务进程和 `current` 均指向 `20260907-voice8`。公众问答采用快速讲解配置，后台工作台仍保留深度推理能力；手机端长按说话、松开结束输入，电脑端点击开始、再次点击结束；“小槌小槌”唤醒后提供提示音与 7 秒收音窗口。线上识别使用腾讯云实时 ASR 和英歌专有热词；朗读使用腾讯云精品音色“智萌”（101015），按完整句边生成边朗读并预合成下一段，本地模型作为后备。页面明确说明语音只用于实时识别，不保存原始录音。地域地图仅展示汕头、揭阳、潮州三个潮汕地区。

公众回答在北京时间 2026-09-16 00:00 至 2026-09-22 23:59:59 自动启用地区脱敏：`广东省` 显示为“某省”，潮汕及所属城市、区县名称显示为“某地区”。窗口外保持原文。

## 目录

### 01_公众网站

线上正在使用的完整公众网站，共 13 个 HTML 页面，包含：

- 首页与中英文切换
- 手机端响应式导航
- 影像、角色、声音、地区及文献专题页面
- Three.js 阵法互动
- “云游英歌”数字展览入口
- 英歌小槌前端对话与实时语音输入
- 网站后台静态界面
- 备案信息

入口文件：`01_公众网站/index.html`

### 02_英歌小槌智能体

#### 01_运行程序

保持服务器项目原有相对结构，包含：

- `backend`：Agent API、RAG 检索、后台、语音、内容审核与运行逻辑
- `backend/models`：约 0.77 GiB 的本地 ASR、唤醒与 TTS 模型
- `agent`：系统提示词、意图、知识清单、黄金问答与评测配置
- `content`：展陈内容配置
- `package.json` / `package-lock.json`：Node.js 依赖清单

#### 02_正式知识库

来自服务器持久化目录，包含：

- `content`：94 份正式知识文档
- `governance`：意图、RAG、黄金答案及评测规则
- `runtime`：知识切片、词法索引、来源注册表和构建报告

#### 03_展陈数据

包含服务器当前展陈目录和公众发布数据。

### 03_部署运维

包含 Nginx、systemd、备份、恢复及环境变量示例。所有文件均为脱敏模板。

## 安全说明

本目录不包含：

- DeepSeek 或腾讯云 API 密钥
- 管理员真实密码及登录会话
- 服务器 SSH 私钥
- 私有审计记录和用户对话数据

`.env.example` 中仅保留字段说明。正式部署时应在服务器安全环境中重新配置密钥。

## 本地预览公众网站

在本目录运行：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\启动公众网站预览.ps1
```

浏览器访问 `http://127.0.0.1:8098/`。本地只预览页面；问答、后台及语音 API 需要启动智能体后端或连接正式服务。
