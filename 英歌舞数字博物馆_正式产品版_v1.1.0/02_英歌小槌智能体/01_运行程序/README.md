# 英歌舞数字博物馆

独立的英歌舞数字博物馆原型仓库。项目从旧工作区中经过筛选迁移，只保留当前 v3 前台、英歌小槌后端、知识检索数据和接管文档。

## 当前能力

- Logo SVG 描边、显影、归位与馆名波浪入场
- Logo 动画之后在首页 Hero 内播放开场短片，并在真实末帧上显现首页文案
- 首页学习入口与九个主题页面
- GSAP 页面转场、滚动动效与 reduced-motion 降级
- Three.js 阵法互动演示
- 中国地图与英歌地区交互索引
- 英歌小槌本地知识库问答接口
- 团队视频与木疙瘩 H5 的明确接入位置（素材尚未交付）
- 可视化内容运营台（草稿、校验预览、分角色发布、版本冲突保护与审计）
- 英歌小槌一键连接诊断（网页、应用、知识运行时、知识源、检索、来源和模型配置）
- 单页运营工作台：账号登录、网站内容、真实素材、英歌小槌、方案历史与模型设置集中管理
- 后台英歌知识证据图谱：全景、来源治理、冲突与缺口三种只读治理视图

后台当前包含一套位于 `web/admin/` 的可视化运营台，以及受保护的管理 API，覆盖内容编辑、素材治理、知识诊断、智能辅助和模型设置。打开 http://127.0.0.1:8096/admin/workspace.html 即可进入；首次使用会创建本机管理员，之后使用账号和密码登录。

网站内容与真实素材编辑器嵌入同一工作台；首页文字支持即时视觉预览、服务端校验预览、草稿保存和受治理发布，断线时不会把浏览器缓存伪装成已保存。证据图谱也在“真实素材”内切换，生产图谱未就绪时明确显示空态，不使用测试数据冒充内容。英歌小槌和方案历史位于同一页面，不再维护独立一级入口。DeepSeek API Key 可在“设置”中输入，密钥加密保存在公众目录之外，浏览器只读取“已配置/已验证”状态。详细流程见 [docs/ADMIN_OPERATIONS.md](docs/ADMIN_OPERATIONS.md)。

## 本地启动

要求：Node.js 22.14+、Python 3。

```powershell
Copy-Item backend/.env.example backend/.env
./start-local.ps1
```

打开：

- 博物馆：http://127.0.0.1:8096/
- 运营工作台：http://127.0.0.1:8096/admin/workspace.html
- 智能体健康检查：http://127.0.0.1:8787/api/health

不启用智能体时，也可以只运行静态站：

```powershell
python -m http.server 8096 --bind 127.0.0.1 --directory web
```

## 项目结构

```text
web/          当前数字博物馆公众前台（不含知识全文索引）
backend/      英歌小槌 HTTP 服务
agent/        智能体配置、私有运行时知识、结构化知识与测试
automation/   运行时审核队列（仓库只保留目录）
docs/         接管说明、方案和审计结论
```
