# 英歌代表性传承人与保护单位档案

## 概念区分

| 概念 | 含义 |
|---|---|
| 代表性项目 | 列入某级非遗名录的项目 |
| 代表性传承人 | 经相应层级认定、承担传承责任的个人 |
| 保护单位 | 具体承担项目保护工作的机构 |

项目入选国家级非遗，不代表所有队员自动成为“国家级传承人”；队长、教练、民间传人也不一定具有政府认定身份。

## 潮阳英歌相关人物

早期国家名录资料列举洪飞鹰、郭耀扬、陈汉隆、姚欣塔、杨卫、周修兴、陈坤利、林阿饱等“主要传承人”。这与制度化的“国家级代表性传承人”不是同一概念。

在未找到个人正式认定页面前，应写：

> 国家名录早期资料列举的潮阳英歌主要传承人包括……

不要为每个人自动添加“国家级”头衔；姓名用字、所属社区、认定层级与在世状态仍需核对。

### 林忠诚（林松）：第六批国家级身份已确认

文化和旅游部于2025年3月正式公布第六批国家级非物质文化遗产代表性传承人。广东省文化和旅游厅公布的广东入选名单明确列出林忠诚（林松），对应英歌（潮阳英歌），申报地区或单位为广东省汕头市。

其国家级批次已经确认，但国家非遗个人页当前仍未显示官方序号、出生日期和详细经历。因此不能把名单排序号当成个人序号，也不能从新闻或含敏感个人信息的附件拼接空缺字段。

## 身份核验流程

1. 查询中国非物质文化遗产网个人页。
2. 查询文化和旅游部或省市正式名单附件。
3. 核对项目全名、编号、地区与批次。
4. 区分新闻简称、队伍内部称谓与制度身份。
5. 对同名者核对出生年份、地区和队伍。
6. 不公开身份证号、私人电话或未授权住址。
