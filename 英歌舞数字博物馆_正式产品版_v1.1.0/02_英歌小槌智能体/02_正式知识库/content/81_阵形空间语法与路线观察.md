# 英歌阵形空间语法与路线观察

## 一、阵名不是路线图

“双龙出海”“八卦阵”“满天星”首先是队伍使用的阵名或视觉意象。仅凭名称，不能知道人数、站位、行进方向、交叉次序、结束造型或鼓点信号。同名阵在不同队伍中也可能不同。

为了让智能体回答到“怎么变”，需要在保留阵名的同时记录可观察的空间操作。

## 二、空间操作的研究词表

| 操作 | 定义 | 记录重点 |
|---|---|---|
| 开 `open` | 队列横向或纵向间距增大 | 哪条轴扩张、起点和最大间距 |
| 合 `close` | 多列向共同中心收束 | 中心点、到达顺序、碰撞余量 |
| 分 `split` | 一列或一团分成两组以上 | 分叉点、领队、组员分配 |
| 并 `merge` | 多组汇为同列或同团 | 汇合点、先后和让位规则 |
| 转 `turn` | 个体或整列改变朝向 | 角度、支撑脚、队列延迟 |
| 穿 `thread` | 一列从另一列或空间缝隙通过 | 入口、出口、交叉点 |
| 绕 `orbit` | 围绕中心、角色或队列运动 | 圆心、方向、圈数 |
| 逆向 `counterflow` | 两组朝相反方向运动 | 分隔带、会遇点、安全距离 |
| 定势 `hold` | 在相对稳定构图中停留 | 持续时间、朝向和动作是否继续 |
| 收队 `exit` | 离开展演点或恢复行进队列 | 出口、队尾和锣鼓位置 |

这些词是数字化描述层，不是传统阵法名。

## 三、甲子空间转换个案

甲子官方专页公开了分行、合拢、穿单龙、穿双龙、穿“8”字和穿龙仔等变化。鼓点变急时，时迁带队完成合拢、分行及若干穿插；另一段文字又记李逵有时带动分行、合拢和单双龙变化。

可据此建立路线观察任务：

1. 标出时迁、李逵、杨志和每一列首位；
2. 确认变阵开始前的队列数与朝向；
3. 找到第一次明显偏离原路径的人；
4. 标出每个交叉点和通过次序；
5. 记录鼓点变急、八拍吆喝和身体启动的先后；
6. 区分“引路角色的路径”与“大队列的几何形状”。

## 四、队伍阵名如何保存

### 原名层

原样保存队伍公开名称，如：

- 后溪：双龙出海、双圈互逆、十字阵、八卦阵、满天星、众星拱月等；
- 联兴：双龙出海、猛虎下山、八卦阵；
- 桃园：瑞龙展须、六合乾坤、三拜谢；
- 慈海：排山倒海、行云流水、燕子翻身、罗汉阵；
- 甲子：穿单龙、穿双龙、穿“8”字、穿龙仔。

### 分析层

只有在连续视频中看见后，才增加 `split`、`merge`、`thread`、`orbit` 等空间标签。原名和分析标签不能互相替换。

## 六、穿双龙怎么记录

不能从名称画一个想象中的双螺旋。应至少确认：

- 起始是两列、四列还是更多子组；
- 两条“龙”的首位是谁；
- 是否互穿、平行、绕行或先分后合；
- 交叉点有几个；
- 同一交叉点的通过顺序；
- 队尾是否完全通过后才收束；
- 鼓点、哨声或领喊在何时出现。

只有正面近景时，交叉深度会被压缩，不能可靠判断谁从谁身前通过。

## 七、街巷与舞台不是同一空间

巡游路线需要适应道路宽度、转角、停点和观众；舞台编排更强调正面构图、固定时长和灯光区。一个队伍在舞台压缩列距或删减穿插，不代表传统阵法已经改变。

空间档案必须记录：

- 场地尺寸与地面；
- 观众区域和安全线；
- 锣鼓组是固定还是移动；
- 是否为排练、巡游、定点或舞台；
- 是否因镜头、直播或主办方时长而改编。

## 八、摄像机可靠性

| 机位 | 最适合 | 主要缺陷 |
|---|---|---|
| 高位固定全景 | 阵形、路线、队列间距 | 看不清脸谱和细槌法 |
| 地面正面全景 | 正面构图与动作一致性 | 深度与前后遮挡 |
| 侧面全景 | 纵向间距、步幅、前后层次 | 阵形横向结构不全 |
| 跟拍 | 角色体验与局部动作 | 路线参照漂移 |
| 特写 | 击槌点、表情、道具 | 几乎不能证明完整变阵 |

最小阵形证据应有一条不中断的固定全景；若只有剪辑宣传片，只能列出镜头中直接可见的局部。

## 九、智能体回答边界

用户问阵法时，按三层回答：

1. 列出具体队伍公开的阵名；
2. 解释阵名不等于统一几何图；
3. 若有同步视频，再给交叉点、路线和信号时间码。
