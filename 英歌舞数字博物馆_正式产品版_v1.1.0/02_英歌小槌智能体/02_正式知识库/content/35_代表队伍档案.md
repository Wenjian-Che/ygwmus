# 英歌代表队伍档案

> [!important] 阅读说明
> 本页记录的是公开资料能够确认的“队伍个案”，不是权威排行榜。队伍的成立年代、板式和套路以公开资料为线索，仍应通过队伍、文化馆和田野调查复核。一个队伍的动作不能自动代表整个地区。
>
> 15支队伍的逐项证据、动作锣鼓阵法对照、来源冲突与传播年表，已分别扩充至《66_代表队伍证据档案扩充》《67_队伍动作锣鼓阵法证据矩阵》《68_队伍资料冲突与时效性审计》《69_代表队伍活动与海外传播年表》。

## 潮阳及汕头地区

### 潮阳西门女子英歌队

| 字段 | 内容 |
|---|---|
| 地点 | 汕头市潮阳区文光街道西门社区 |
| 队伍性质 | 女子英歌队 |
| 公开成立时间 | 1952年成立；停滞多年后于2011年在社区帮助下重新组建 |
| 公开记录的传统 | “老五下套”打法 |
| 当代变化 | 在传统打法基础上创新对打、单打等套路 |
| 研究价值 | 女性参与、代际传承、身体表达与媒介传播 |
| 证据等级 | A：汕头市直党建网、中国非物质文化遗产网转载人民日报 |

中国非物质文化遗产网转载人民日报的完整报道已明确解释两个年份：1952年是队伍成立时间，2011年是停滞多年后的重新组建时间。研究其创新时，仍应区分老套路、当代恢复、重新编排和面向镜头的展示段落。

来源：

- [汕头市直党建网：2024英歌舞展演队伍介绍](https://stszgw.shantou.gov.cn/stszdj/yaowen/202402/eee3e4d18bc84d32837339a823667eb6.shtml)
- [共青团汕头市委：女子英歌“不如男”？](https://youth.shantou.gov.cn/youth/tqkd/202401/ec24b71d5c89465caf0e654d162eb2fa.shtml)

### 文光岭东英歌队

| 字段 | 内容 |
|---|---|
| 地点 | 汕头市潮阳区文光街道岭东社区 |
| 公开成立时间 | 解放初期 |
| 板式 | 潮阳慢板代表之一 |
| 特色称谓 | “醉槌英歌舞” |
| 身体特点 | 似醉非醉、刚柔相济、步态沉稳 |
| 研究价值 | 慢板节奏、长槌、太极/舞蹈身体解释 |
| 证据等级 | A：汕头市直党建网公开资料 |

“醉槌”描述的是特定风格的身体状态和槌法气质，不宜理解为舞者真的饮酒，也不应扩展为所有慢板英歌的统一特征。
