# 英歌脸谱与服饰视觉辨识指南

> [!warning] 核心原则
> 仅凭颜色不能可靠识别角色，仅凭一张照片也不能可靠判断队伍或流派。视觉辨识必须结合地点、队名、节目单、领舞位置、道具、服装和队伍自身解释。

## 从“猜人物”改成“分层观察”

### 第一层：可直接看见

- 面部主色、辅色和线条；
- 眉、目、额、鼻、腮的图案结构；
- 是否对称、是否有文字或动物纹样；
- 头冠、雉尾、头巾、绒球；
- 上衣颜色、襟型、袖口、绣纹；
- 裤、绑腿、脚绞、鞋和铃铛；
- 双槌、令旗、蛇形道具、小铃鼓或兵器；
- 队列位置与动作方式。

### 第二层：可以提出的假设

- 可能属于梁山人物造型；
- 可能是头槌、时迁或其他特殊角色；
- 可能采用某一队伍公开出现过的服饰组合。

### 第三层：必须有外部证据才能确认

- 具体人物姓名；
- 具体队伍；
- 板式和师承；
- 年代、活动和非遗身份；
- “传统原版”或“创新版本”。

## 脸谱记录字段

| 区域 | 记录内容 |
|---|---|
| 底色 | 白、红、黑、蓝、绿、肤色或复合底色 |
| 额部 | 图案、文字、月牙、火焰、动物或几何纹 |
| 眉部 | 粗细、方向、是否上挑、是否连至额部 |
| 眼部 | 眼窝形状、包围色、延伸方向 |
| 鼻部 | 鼻窝、鼻梁线、主色 |
| 腮部 | 色块、旋纹、放射纹、留白 |
| 口部 | 唇色、嘴角线、胡须 |
| 对称性 | 完全对称、局部不对称、歪脸式 |
| 绘制方式 | 手绘、模板、贴饰、面具或混合 |
| 队伍解释 | 由谁说明、何时记录、是否公开 |

## 为什么通用色彩表不可靠

“红忠、黑刚、白奸”的简表主要来自大众化戏曲脸谱解释。英歌脸谱确实受戏曲影响，但还会受以下因素改变：

- 梁山人物在地方队伍中的重新分配；
- 村落师承和绘脸艺人的个人体系；
- 户外远距离观看对高对比度的要求；
- 舞台灯光、摄影和短视频传播；
- 女子、儿童队伍及新编节目；
- 颜料、时间、预算和绘制速度。

因此，智能体应回答“这个脸谱以红色为主”，而不是直接回答“红色所以一定是关胜”。

## 甲子英歌脸谱样本

汕尾市政府资料提供了较明确的甲子个案：

- 武畔前24人各画不同花脸；
- 24张脸谱互不相同；
- 眉、目、额、鼻、腮的造型和着色变化较大；
- 通过浓淡繁简、曲直粗细的对比塑造人物；
- 与京剧、粤剧、西秦戏净角面谱存在相似，但形成自身体系。

这说明“同一队伍内部的角色脸谱谱系”比“全英歌统一颜色表”更适合作为知识组织单位。

来源：[汕尾市人民政府：国家级非遗之甲子英歌](https://www.shanwei.gov.cn/slhwz/zjsw/content/post_1104466.html)

## 甲子英歌服饰样本

### 武畔

- 白襟环花束袖黑衫；
- 双手持木棍；
- 头戴红色、插雉尾的双龙武生冠；
- 红裤、五彩脚绞；
- 足穿带小铃的草鞋。

### 文畔

- 天蓝色上衣；
- 手提小铃鼓；
- 其他武侠造型与武畔有相通处。

### 特殊角色

- 时迁：官方资料记载头插金花、戴红绸武冠、手舞银蛇；
- 花鼓公/花鼓婆：持小铃鼓或花鼓槌，可在队伍中较自由移动。

上述组合首先适用于甲子英歌，不能据此解释潮阳、普宁全部队伍。

## 潮南西岐公开视觉样本

官方活动报道可确认：

- 身着绣袍；
- 脸画浓妆；
- 手持双槌；
- 以三十六天罡、七十二地煞为人物叙事。

但报道没有给出每张脸谱与具体人物的对应表，因此只能作为“队伍整体视觉描述”，不能拆成角色识别规则。

## 西门女子英歌观察重点

- 是否沿用传统队伍的脸谱构图；
- 女性英雄叙事与梁山叙事如何并存；
- 老五下套、单打和对打时服饰是否不同；
- 发型、头饰和舞台化妆是否随年代变化；
- 队伍如何解释“刚、柔、飒爽”等媒介标签。

## 图像识别回答模板

### 信息不足

> 从画面可以确认舞者使用双槌、脸谱以黑白/红色为主，并穿着××服饰。但英歌脸谱因队伍而异，仅凭颜色无法可靠判断具体角色。若能提供演出地点、队伍名称或节目单，我可以进一步比对。

### 有队伍信息

> 这张图来自××队。根据该队公开资料，××角色通常使用××道具；画面中的队列位置和道具与之相符，因此“可能是××”。但最终仍应以队伍说明为准。

### 不允许的回答

- “红脸必然是关胜。”
- “这个图案证明是最正宗的古脸谱。”
- “看服装就知道有六百年历史。”
- “女性脸谱一定更柔美。”

## 视觉样本采集

每套脸谱/服饰至少采集：

1. 正面标准照；
2. 左右45度；
3. 闭眼或绘制中的局部步骤；
4. 头冠、上衣、腰部、腿部和鞋的分件照；
5. 自然光色卡；
6. 穿着者、绘脸者和队伍说明；
7. 角色名、队伍、日期、活动；
8. 是否为传统版本、复原版本或新编版本；
9. 使用和公开授权。
