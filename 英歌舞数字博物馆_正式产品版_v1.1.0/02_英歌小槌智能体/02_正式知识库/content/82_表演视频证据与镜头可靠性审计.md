# 英歌表演视频证据与镜头可靠性审计

## 一、视频能证明什么取决于怎么拍

视频不是天然完整证据。一个脸谱特写可证明当时画面中的颜色和纹样，却不能证明完整队形；一个航拍全景可展示路线，却未必能分辨每次槌击；替换音乐的短视频不能证明传统鼓点。

## 二、六项入口检查

1. **来源**：原拍摄者、队伍、主办方还是二次搬运？
2. **队伍**：是否有队名、地点、日期或节目单互证？
3. **连续性**：是否跳剪、转场、重复镜头或插入慢动作？
4. **速度**：是否变速，原始拍摄帧率和播放倍率是什么？
5. **声音**：是否保留现场原声，音画是否同步？
6. **授权**：是否允许研究标注、模型检索和网页展示？

缺少队伍和地点的视频仍可做客观描述，但不能用脸谱、服饰或速度强行认村认派。

## 三、不同问题所需的最低镜头

| 研究问题 | 最低证据 | 不足的镜头 |
|---|---|---|
| 槌的接触点 | 正常速度中近景，双人全臂可见 | 只拍脸或只拍槌端 |
| 落脚与重心 | 全身侧面或斜侧面 | 腰部以上特写 |
| 队形开合 | 固定不中断全景 | 手持跟拍、频繁切镜 |
| 穿双龙路线 | 高位或多机位全景，交叉全过程 | 单一正面近景 |
| 鼓点与动作同步 | 原声、可见击打事件、连续时间轴 | 替换配乐或音画漂移 |
| 角色职责 | 连续观察其在多个段落中的行为 | 一张定妆照 |
| 整场结构 | 从集结、入场到收势/转场的长记录 | 高潮混剪 |

## 四、变速与慢动作检查

可能的变速线索包括：

- 人声、哨声或鼓声整体音高异常；
- 帧重复、光流补帧或运动边缘变形；
- 同一镜头内部速度突然变化却无动作原因；
- 画面时长与原平台标记不一致；
- 元数据标称高帧率但导出为普通帧率。

无法拿到原文件时，应标记 `speed_integrity: unknown`。未知不等于造假，只意味着不能用该片段计算BPM、步频或动作时长。

## 五、剪辑对因果判断的影响

若画面依次出现“鼓点变急—队形打开”，只能在镜头连续、原声连续且没有错位时，记录为时间先后。要认定前者是约定信号，还需要：

- 多次重复出现同一关系；
- 司鼓、领队或队员口述；
- 队伍谱本或训练视频；
- 排除哨声、视觉领队和现场空间变化等其他信号。

宣传片常把不同场次、不同段落拼接成一条视觉叙事，不能据此建立动作谱。

## 六、音画同步校验

优先选取三类可见瞬态：

1. 鼓槌接触鼓面；
2. 两支英歌槌发生可见接触；
3. 脚掌清楚落地。

分别测量片头、中段和片尾的声音峰值相对画面接触时间。若偏移恒定，可记录统一校正值；若偏移逐渐扩大，应分段处理并标记漂移。

```yaml
sync_check:
  method: visible_transient
  points:
    - video_time:
      event:
      audio_offset_ms:
  constant_offset_ms:
  drift_ms_per_min:
  correction_applied:
  confidence:
```

## 七、视频证据等级

| 等级 | 条件 | 可用于 |
|---|---|---|
| V1 | 原文件、原声、连续、多机位、有队伍元数据和授权 | 动作—鼓点—队形同步分析 |
| V2 | 官方或队伍发布、原声基本连续、单机位 | 直接可见范围内的队伍个案 |
| V3 | 来源可追溯但有剪辑或配乐 | 造型、活动出现与局部动作 |
| V4 | 二次搬运、无地点日期、变速不明 | 只做客观画面描述 |
| VX | 来源或授权风险明显 | 不入库或隔离审查 |

官方发布提高的是来源可信度，不会自动补足被剪掉的时间或看不见的脚步。

## 九、智能体如何回答“这个视频能不能分析”

推荐结构：

1. 明确当前能观察什么；
2. 列出缺失的队伍、地点、原声、连续性或帧率；
3. 将结论分为画面事实、时间关系和机制推断；
4. 给出需要补充的最小材料；
5. 不因视频“看起来很专业”就提升证据等级。

## 十、与西门女子队史的示例

公开视频或报道若只说“2011年出现女子队”，曾不足以解释1952年队史。中国非物质文化遗产网转载人民日报的完整报道明确给出：西门女子英歌队1952年成立，停滞多年，2011年在社区帮助下重新组建。这个案例说明，时间点必须先区分“初建、停滞、重组”，不能只比较两个年份大小。
