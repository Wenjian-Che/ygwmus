# 英歌影像资料与检索

## 影像类型

| 类型 | 研究价值 | 常见缺陷 |
|---|---|---|
| 完整巡游 | 路线、节奏、观众和结构 | 机位移动、声轨混杂 |
| 固定全景 | 队形和空间 | 缺少动作细节 |
| 近景 | 脸谱、槌法和表情 | 看不到整体队形 |
| 排练 | 教学语言与错误修正 | 可能不允许公开 |
| 访谈 | 师承、名称和队伍史 | 记忆需互证 |
| 旧照片录像 | 年代变化 | 日期、人物和地点易缺失 |
| 新闻短片 | 当代事件 | 剪辑和宣传选择明显 |
| 短视频 | 传播与视觉高潮 | 常省略上下文 |

## 优先检索来源

1. 中国非物质文化遗产网；
2. 文化和旅游部、省市政府与文化馆；
3. 队伍官方账号；
4. 电视台、新华社等媒体；
5. 学术数据库和纪录片；
6. 自媒体仅作线索。

## 检索字段

不要只搜“英歌舞”，组合：

- 地区/村社 + 队伍；
- 年份 + 春节/元宵/活动；
- 动作/板式/角色；
- 文化馆/传承基地；
- 完整版/固定机位/排练/访谈。

## 真实性检查

- 发布日期不等于拍摄日期；
- 合集可能混入不同队伍；
- 配乐可能覆盖原锣鼓；
- 慢放、加速和剪辑会改变动作判断；
- 标题中的“最古老、正宗、百亿”需另查来源；
- AI修复和生成画面必须标注；
- 公共屏播放不等于队伍现场出访。

## 拍摄建议

至少保留：

- 一条不切镜完整段落；
- 固定全景；
- 正面、侧面动作；
- 锣鼓组独立声音；
- 场记和统一时间；
- 队伍、人物和未成年人授权。
