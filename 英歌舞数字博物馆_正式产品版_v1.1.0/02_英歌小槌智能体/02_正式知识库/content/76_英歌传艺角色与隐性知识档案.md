# 英歌传艺角色与隐性知识档案

> [!important] 保护“会做的人”
> 英歌不是只由台前舞者构成。司鼓、教练、绘脸者、服装头饰人员、器材师、组织者和影像记录者共同保存大量难以写成文字的隐性知识。现有公开资料对这些人的姓名记录很少，本页先建立角色级知识模型，不虚构具体人物。

这些队伍角色不自动成为非遗代表性传承人；正式认定层级必须回查相应主管部门公布的个人名单。

## 一、传艺角色总表

| 角色 | 核心知识 | 典型可观察产物 | 缺失后会发生什么 |
|---|---|---|---|
| 教练/教头 | 动作动力链、步法、槌路、队形、体能、安全、风格边界 | 训练口令、分解示范、纠错记录 | 动作只剩外形，失去发力和转换逻辑 |
| 头槌/领舞 | 起势、路线、节拍确认、队形空间、临场引导 | 领舞轨迹、哨声或视觉信号 | 队伍入场和转向不稳 |
| 司鼓 | 基础脉冲、段落、转换信号、速度和现场调度 | 鼓谱、拟声谱、分轨音频、时间码 | 动作与队形失去共同时间骨架 |
| 绘脸者 | 人物候选、构图顺序、颜色配比、演出时长与队伍谱系 | 正面/侧面照片、分步视频、色卡 | 脸谱被简化成通用戏曲模板 |
| 服装头饰人员 | 穿戴顺序、绑扎、尺寸、散热、视线、维修 | 穿戴清单、尺寸表、修缮记录 | 造型不稳并增加运动风险 |
| 器材师 | 英歌槌与锣鼓的材料、尺寸、重量、平衡、维护 | 实物测量、制作流程、维修记录 | 道具影响动作或出现安全隐患 |
| 队伍组织者 | 招募、排练、演出、经费、交通、社区协调 | 名册、日程、账目、章程 | 传承难以持续，资料散失 |
| 影像记录者 | 机位、声画同步、元数据、授权和长期保存 | 原始视频、时间码、授权书 | 只剩剪辑短视频，无法复原过程 |

## 二、教练保存的知识

教练不只是“教会动作”，还需要在多个层次传递：

1. 动作名称与该队自己的叫法；
2. 起势、发力、击槌、复位的先后关系；
3. 重心高度、步幅和转身半径；
4. 与鼓点、吆喝、哨声和前排视觉信号的对应；
5. 队形密度、穿插路线和安全距离；
6. 哪些动作属于常规套路，哪些是舞台改编；
7. 不同年龄、体能和场地的训练调整。

只保存一段正式演出视频，无法完整记录纠错方法、练习顺序和失败案例。

## 三、司鼓保存的知识

司鼓档案至少分六层：

| 层级 | 记录内容 |
|---|---|
| 乐器 | 鼓、锣、钹等配置与尺寸 |
| 基础循环 | 一段反复节奏的拍数、重音和速度范围 |
| 段落句法 | 起鼓、过门、加密、停顿、尾句与收势 |
| 动作对应 | 哪个信号提示起势、对槌、转向或收势 |
| 队形对应 | 哪个信号提示合拢、分行、穿插 |
| 临场调度 | 路线堵塞、队伍拉长、观众靠近时怎样调整 |

甲子英歌公开资料可作为一个具体例子：动作变化前可能有八拍吆喝，鼓点变急时配合合拢、分行、穿“8”字和穿双龙等变化。但这不能被复制成全部英歌的统一信号表。

### 司鼓采访最小问题集

- 每段鼓点在本队叫什么？
- 是固定拍数还是可以延长？
- 哪个声音是段落边界，哪个只是装饰？
- 舞者听鼓、看领舞还是同时使用两种信号？
- 巡游转角和舞台定点演出是否使用同一版本？
- 临时减员、加速或停演时怎样发信号？

## 四、绘脸者保存的知识

官方高校案例说明，英歌脸谱、服装和动作通常通过师傅示范传递；汕头职业技术学院又以研究和设计方式形成108个脸谱、108套服装的当代项目。两种情况都提醒我们：

- 队伍旧谱、师徒实践和高校当代设计必须分层保存；
- 同一人物在不同村落、绘脸者和年代中可能有差异；
- 颜色不能脱离构图、角色候选和队伍说明单独解释；
- “红脸就是忠、黑脸就是刚”只能作戏曲常识线索，不能直接识别英歌人物。

### 绘脸档案最小单元

```yaml
队伍:
演出日期:
绘脸者:
角色称谓:
人物候选:
底色:
眉眼:
鼻梁:
额纹:
左右对称:
颜料和工具:
绘制时长:
来源版本:
是否当代设计:
授权:
```

## 五、服装、头饰与器材人员保存的知识

英歌服装和头饰必须与高强度动作共同考虑：

- 头饰绑扎不能遮挡视线或在转身中松脱；
- 翎羽和装饰需要预留舞者、观众及同伴安全距离；
- 服装层数、面料和护具影响散热；
- 鞋底摩擦、槌的重量和平衡影响落脚、转身和对击；
- 儿童训练道具不能直接照搬成人演出道具。

器材档案应记录实物，而不是只抄项目概述中的一个尺寸。国家名录概述中的短棒尺寸是概括性材料，不代表慢板、中板、快板和各队实物完全一致。

## 六、为什么这些角色不等于代表性传承人

司鼓、绘脸者、教练、队长或器材师不自动成为非遗代表性传承人。一个优秀司鼓、绘脸者或器材师可能保存项目不可替代的知识，但“代表性传承人”仍是经相应层级正式认定的制度身份。智能体应同时做到：

- 尊重并记录这些人的实际贡献；
- 不擅自添加国家、省、市、县区级头衔；
- 在人物同意后记录姓名、口述和作品；
- 允许人物选择实名、化名或仅以角色入档；
- 不因未获政府称号就把其知识视为次要。

## 七、隐性知识采集包

每个角色至少采集：

1. 一次半结构化访谈；
2. 一段完整工作过程视频；
3. 一段慢速分解示范；
4. 一次真实演出中的同步记录；
5. 一份术语、工具或材料表；
6. 一份知情同意与使用授权；
7. 一次由受访者本人校对的摘要。

对于司鼓，应增加多轨音频和舞者同步视频；对于绘脸，应增加自然光色卡与正侧面照片；对于器材，应增加尺寸、重量和材料测量。

## 八、智能体问答边界

### “司鼓就是传承人吗？”

不一定。司鼓是表演与传艺角色，掌握节奏和临场调度知识；代表性传承人是政府认定身份。某人可以兼具两种身份，但需要分别核对队伍资料和正式名单。

### “脸谱是谁画的？”

公开资料通常不足以回答某场演出的具体绘脸者。需要演出日期、队伍、后台记录或队伍确认。智能体可以解释绘制和识别方法，不应凭照片猜具体艺人。

### “能不能给我一套统一鼓谱？”

不能把一个队伍的鼓谱包装成所有英歌的标准。应先确认地区、队伍、板式和段落，再由该队司鼓口述、鼓谱及同步视频共同核验。
