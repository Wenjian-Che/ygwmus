# 英歌道具与服饰

## 基本原则

道具和服饰应按队伍、角色、板式、年龄与年代记录。不存在一套适用于所有英歌的标准装备清单。

## 英歌槌

- 持槌群舞的核心器物；
- 通常成对使用；
- 产生视觉轨迹和集体声响；
- 长度、粗细、重量和重心随队伍与板式变化；
- 慢板资料明确提到舞棒较长。

制作与测量见 [[19_英歌槌制作工艺详解]]。

## 指挥与特殊角色道具

| 道具 | 可能使用者 | 边界 |
|---|---|---|
| 令旗 | 部分队伍的指挥性角色 | 人物对应因队而异 |
| 蛇形道具 | 部分队伍的时迁 | 材质、颜色和功能不同 |
| 小铃鼓 | 甲子文畔、花鼓角色等个案 | 不能推广为全部英歌 |
| 兵器 | 后棚、角色展示或舞台改编 | 需区分真器械、道具和象征性配件 |

## 锣鼓乐器

常见鼓、锣、钹、镲等打击乐器，螺号、唢呐和其他乐器按地区与场景配置。不要把某队数量写成统一标准。详见 [[39_锣鼓节奏与声音档案]]。

## 服装层次

记录时拆分：

1. 头冠、头巾、雉尾、绒球；
2. 上衣的襟型、袖型、底色和绣纹；
3. 腰带、护具与兵器挂件；
4. 裤装、绑腿和脚绞；
5. 鞋、草鞋与铃铛；
6. 脸谱、胡须和其他面部附件。

## 甲子样本

汕尾市政府资料记录：

- 武畔穿白襟环花束袖黑衫，持双木棍；
- 文畔穿天蓝色衫，持小铃鼓；
- 头戴红色、插雉尾的双龙武生冠；
- 穿红裤、五彩脚绞和带铃草鞋。

这是一套甲子个案，不是潮阳或普宁统一服装。

来源：[汕尾市政府：国家级非遗之甲子英歌](https://www.shanwei.gov.cn/slhwz/zjsw/content/post_1104466.html)

## 材料如何变化

- 户外巡游重视耐用、通风和远距离辨识；
- 舞台灯光可能促使使用反光或高饱和材料；
- 儿童服装需要减重和避免尖锐装饰；
- 海外、剧场与短时表演可能使用便于运输的版本；
- 旧服装修补与新制服制作应分别建档。

## 安全

- 头冠固定牢靠且不遮挡视线；
- 服装不妨碍深蹲、转身和挥槌；
- 雉尾、兵器和装饰留足人群距离；
- 鞋底适应地面并防滑；
- 儿童版本减少重量和硬质突出物；
- 演出前检查槌、旗杆、兵器和扣件。

## 视觉辨识

仅凭服装不能确认年代、队伍或角色。必须结合地点、节目单、道具、队列位置和队伍说明，见 [[38_脸谱服饰视觉辨识指南]]。
