# 知识问答证据分层与阅读规范

这份规范用于英歌舞智能体，不是英歌舞历史事实本身。它规定如何把已经核验的资料转成公众容易阅读、研究者可以追溯的回答。

## 一、先回答问题，再展示证据

用户首先需要知道问题的结论，不能一打开回答就看到长串文件名、网址或审核术语。推荐顺序是：第一段直接回应问题；第二段解释原因、动作、人物或地区差异；最后用紧凑的“来源依据”区域承载证据。证据是支撑回答的底座，不应取代回答本身。

## 二、证据等级

- A 级：政府部门、国家级非遗名录、中国非物质文化遗产网、地方标准和正式公告。
- B 级：地方志、学术专著、论文、正式调查和学校研究项目。
- C 级：队伍公开介绍、传承人口述、演出手册、连续现场视频和照片。
- D 级：新闻转述、短视频、二次整理和未完成核验的动态候选。

高风险事实（起源、唯一正宗、代表性传承人身份、非遗级别、精确人数、当前活动）至少需要一条 A 级或两条相互独立的 B/C 级证据；只有 D 级材料时，应回答“目前无法确认”，而不是把传播内容写成事实。

## 三、通用事实与地方个案必须分开

“英歌常见的表演机制”可以作为通用说明；“潮阳某队的八拍吆喝”“甲子某队的 107 人结构”“普宁某村的阵法名称”只能作为对应地区、队伍或资料时段的个案。回答中要明确使用“通常”“该资料记录”“在该队公开介绍中”等限定词，避免把一个队伍的做法推广成全国统一标准。

## 四、不同问题使用不同证据

- 定义题：优先项目名录、地方标准和总纲资料。
- 原因题：优先动作、锣鼓、角色协同和文化意义资料，并把解释推断与原文事实分开。
- 比较题：至少同时检索两个地区或队伍的资料，按同一维度比较。
- 图片题：只能描述可见的服饰、脸谱、道具和队形；没有地点、队名和连续影像时，不确认具体人物或流派。
- 实时题：必须显示数据截至时间；静态知识只能作为背景，不能冒充当天活动信息。

## 五、公众端引用展示规则

默认只展示 1—3 条最相关的来源卡片，并在卡片中显示来源等级、发布机构、标题和“支持哪些内容”。如果存在更多证据，折叠到“查看其余来源”，避免回答被来源列表切断。高风险回答可展示 2—3 条主来源；研究模式再允许展开完整证据链。

正文使用 `[证据1]`、`[证据2]` 这样的短编号与来源卡片对应，不在正文反复粘贴 URL。来源卡片可以打开原始页面，但不能把内部 Markdown 文件名当作面向公众的正式来源标题。

## 六、后台端证据展示规则

后台不是简单复制 C 端卡片，而应额外展示：召回切片、标题路径、BM25 分数、领域重排原因、证据等级、冲突字段、资料更新时间、回答逐句支持率和缺口。管理员可以看到全部证据与内部文件名，公众只看到经过整理的来源标题和链接。

## 七、回答质量门禁

回答生成后至少检查：是否第一段回应了原问题、关键事实是否能在证据中找到、引用编号是否存在且未越界、是否混淆地区或队伍、是否把推断写成事实、是否泄露内部路径或密钥。任一高风险检查失败，答案应降级为“待核实”并进入后台复核队列。

## 八、阅读体验原则

证据越多不等于答案越可信。对公众端，过多来源会增加视觉噪声、降低首屏可读性和移动端滚动效率；对研究者，完全隐藏证据又会降低可复核性。因此采用“正文简洁 + 1—3 条主来源 + 可展开完整证据”的渐进披露方式，让可信度和阅读效率同时保留。
