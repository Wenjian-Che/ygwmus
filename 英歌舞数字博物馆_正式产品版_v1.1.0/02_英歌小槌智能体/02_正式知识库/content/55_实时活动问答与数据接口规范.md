# 英歌实时活动问答与数据接口规范

演出时间、路线、票务、交通、天气和临时停演不能由静态知识库直接回答。本页定义智能体如何查询、合并和展示实时信息。

## 静态知识与实时数据分工

| 问题 | 静态知识库 | 实时数据源 |
|---|---|---|
| 为什么春节常有英歌 | 可回答文化与仪式背景 | 非必需 |
| 今天哪里有表演 | 只提供查询方法 | 必须 |
| 某队历史与风格 | 可回答已审校档案 | 当前阵容仍需核对 |
| 几点封路、怎么停车 | 不保存为长期事实 | 必须 |
| 是否免费、是否要票 | 不可凭往年推断 | 必须 |
| 因雨取消了吗 | 不可回答 | 必须查最新公告 |

## 来源优先级

1. 主办方、当地政府、文旅或公安交管最新公告；
2. 保护单位、参演队伍官方账号；
3. 场馆或票务平台正式页面；
4. 主流媒体转引；
5. 用户投稿与自媒体，仅作为待核线索。

同一活动冲突时，优先比较**发布主体、发布时间、是否明确“调整/取消”**，不能只按搜索排名。

## 查询前必需实体

- 日期：明确到哪一天；“春节”还需年份。
- 地区：至少到城市或区县。
- 需求：看演出、路线、票务、交通中的哪一项。

缺少日期或地区时先追问。若用户允许定位，可将定位转成候选地区，但必须让用户确认。

## 状态机

```text
rumored（线索）
  → announced（已公告）
  → scheduled（安排确认）
  → changed（已调整）
  → cancelled（已取消）
  → completed（已结束）
```

每次更新保留旧记录，通过 `supersedes` 指向被替代版本，避免缓存继续显示过期路线。

## 回答格式

> 截至 2026-02-18 08:30（北京时间），主办方公告显示：……  
> 地点：……；时间：……；票务：……；交通：……。  
> 最新来源：主办方链接。临近出发请再次核对，天气或现场管控可能导致变化。

如果未查到：

> 截至当前查询时间，尚未找到主办方可核实的正式安排。我可以确认该地区有英歌传统，但不能据往年活动推断今天一定有演出。

## 缓存与刷新

| 距活动开始 | 建议缓存 |
|---|---|
| 30天以上 | 24小时 |
| 7—30天 | 6小时 |
| 24小时—7天 | 1小时 |
| 24小时内 | 10分钟 |
| 已标记调整或恶劣天气 | 每次请求或5分钟 |

页面必须同时显示“发布时间”和“最后核对时间”，不能只显示“最新”。

## 安全与体验

- 不承诺一定能占到观看位置。
- 不根据巡游路线鼓励翻越隔离带或进入队伍。
- 交通建议以交管公告为准。
- 儿童、老人和行动不便者应提示拥挤、噪声与疏散风险。
- 用户共享定位时只保留完成查询所需的最低精度。
