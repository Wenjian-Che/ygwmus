# 潮阳英歌七种基础队形地方标准档案

本档案只回答《DB4405/T 315—2025 非物质文化遗产 潮阳英歌》附录 D 明确列出的基础队形。它是潮阳英歌地方标准，不应自动外推为普宁、潮南、惠来、甲子或全国英歌队伍统一使用的阵法谱。

## 直接结论

地方标准列出七种基础队形：**双列队形、方形阵、双龙出海、田螺阵、麦穗花阵、四海升平、八卦阵**。

回答“潮阳英歌有哪些标准队形”时，应先给出这七项，再说明不同队伍会在人数、路线、速度、鼓点、动作组合和称谓上保留自身做法。回答其他地区或具体队伍时，不能直接套用本档案。

## 七种队形逐项辨析

### 1. 双列队形

- **空间结构**：两列平行、左右对称。
- **行进关系**：两列同步向前，是最基础的巡游队形。
- **观察重点**：列间距、左右是否齐进、领队与后排怎样维持轴线。
- **不能误写**：不能把所有两列行进都命名为“双龙出海”；后者包含从中间分开并向两侧展开的路径变化。

### 2. 方形阵

- **空间结构**：两列构成一组，两组并列，形成四列矩形方阵。
- **行进关系**：四列保持相对平行，以较稳定的纵横间距共同移动。
- **观察重点**：横向对齐、纵向排距和转向时方阵是否保持整体。
- **不能误写**：这里的“方形”描述相对站位，不等于舞台上必须出现几何意义上的正方形。

### 3. 双龙出海

- **空间结构**：两组或四组对称队列。
- **行进关系**：队伍从中间分开，逐步向左右两侧展开；标准附图呈现左右对称的弯曲路线。
- **观察重点**：中轴分流、两侧展开的同步性、曲线末端如何衔接下一段。
- **不能误写**：名称相同不保证不同地区、不同队伍的路线完全一致；本条只对应潮阳英歌地方标准图示。

### 4. 田螺阵

- **空间结构**：单列队伍盘成螺旋圆形。
- **行进关系**：可由外向内盘旋，也可由内向外退出。
- **观察重点**：螺旋入口、中心转折、内外圈间距和退出路径。
- **不能误写**：不是普通圆阵；关键特征是单列沿螺旋连续行进。

### 5. 麦穗花阵

- **空间结构**：大小两组形成大圆与小圆的嵌套关系。
- **行进关系**：大队沿大圆行进，小队在内圈反向穿行，形成大小圆交错。
- **观察重点**：两圈方向、内外圈速度差、穿行时的安全距离。
- **不能误写**：不能仅凭静止截图断言“麦穗花阵”，需要看到大小圆及相对运动。

### 6. 四海升平

- **空间结构**：全队均分为四组，在十字方位形成四个对称圆圈。
- **行进关系**：四圈同时转动并维持四方对称。
- **观察重点**：四组人数是否相对均衡、圆心位置、四圈启动和收束是否同步。
- **不能误写**：四个点群不等于四海升平；需要同时具备四组、四圆和对称转动关系。

### 7. 八卦阵

- **空间结构**：外圈、内圈与内圈中的 S 形队列共同构成整体图形。
- **行进关系**：两列衔接为内外圆，内圈的乐队或相关站位呈 S 形组织，标准附图还标示 S 形两侧站位。
- **观察重点**：内外圈方向、S 形中轴、圆与中轴的相对位置。
- **不能误写**：不能因出现一个圆或 S 形就判断为八卦阵，应核对完整空间关系与队伍口述。

## 智能体回答模板

### 用户问“英歌有哪些阵形”

优先回答：

> 若限定为潮阳英歌，2025 年汕头市地方标准明确列出七种基础队形：双列队形、方形阵、双龙出海、田螺阵、麦穗花阵、四海升平和八卦阵。它们分别体现平行行进、四列方阵、左右分流、螺旋盘旋、大小圆反向穿行、四圆对称和内外圆加 S 形结构。不同地区与具体队伍不一定使用同一名称或同一路线，因此不能把这七种写成“全国统一阵法”。

### 用户给出照片问“这是哪种阵”

只凭单张照片通常不能确认。应追问或核对：

1. 队伍所属地区和名称；
2. 前后至少 10—20 秒连续视频；
3. 队列进入、变化和退出路线；
4. 内外圈或分流方向；
5. 队伍传承人、教练或公开谱图的称谓。

## 数字展陈绘图规则

- 页面图形应标注“依据 DB4405/T 315—2025 附录 D 重绘”。
- 图形只能表达相对站位与运动路径，不应假装是某支队伍的逐拍复原。
- 圆阵必须区分普通圆、螺旋、大小圆、四圆与内外圆加 S 形。
- 动画切换应展示路径变化，不能只把同一批圆点随机散开再聚合。
- 若加入非标准列出的队形名称，应另列“具体队伍个案”，并给出队伍与来源。
