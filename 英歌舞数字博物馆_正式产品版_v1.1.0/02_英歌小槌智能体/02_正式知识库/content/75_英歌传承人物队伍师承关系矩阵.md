## 二、三种“传承链”必须分开

### 1. 有姓名的直接学艺链

当前国家级个人页中最明确的一条是：

```text
余荣等甲子老艺人
  → 林炳光（12岁开始学习）
  → 2001年开始授徒
  → 官方页面形成时记载五十多名徒弟
```

“余荣等”说明来源并非只有一人；在未获得完整申报材料前，不补齐其他姓名，也不把所有徒弟写成正式代表性传承人。

### 2. 家族传承链

杨卫官方个人页只明确“通过家族承传方式学习”，没有公开具体亲属姓名。知识图谱应保存：

```yaml
source_person: 未公开
target_person: 杨卫
relation: 家族传承
confidence: A级来源确认关系类型，人物端点不完整
```

不能为了让关系图“看起来完整”而根据同姓或地方口述补出父亲、叔伯姓名。

### 3. 队伍和平台传承链

现代英歌传承大量发生在团体和机构中：

- 陈来发通过南山英歌队长期担任头槌、队长和教练；
- 林忠诚英歌舞技能大师工作室与汕头职业技术学院课程、社团、产业学院相连；
- 古帅青年英歌队以团体方式为海外学员提供动作、脸谱和服装交流教学；
- 保护单位为传承提供场所、档案和组织条件，但不等同于具体授艺者。

这一类关系应写成“参与教学、平台合作或团体辅导”，不强行改写成传统师徒关系。

## 三、队伍职务与传承作用

| 职务/身份 | 可能承担的知识 | 能否自动写成代表性传承人 |
|---|---|---|
| 头槌/领舞 | 起势、路线、节拍、领队信号、角色表现 | 不能 |
| 教练/教头 | 动作、步法、队形、体能、安全和风格校正 | 不能 |
| 队长/组织者 | 人员、演出、训练、对外联络、资源协调 | 不能 |
| 司鼓 | 节奏循环、段落边界、转换信号、临场调度 | 不能 |
| 绘脸者 | 人物谱系、构图、颜料、时间安排与造型边界 | 不能 |
| 服装/头饰人员 | 穿戴顺序、尺寸、视线、散热与维护 | 不能 |
| 器材师 | 英歌槌、锣鼓等器物制作、选材、修缮和安全 | 不能 |
| 代表性传承人 | 经认定承担代表性传承责任 | 需要正式名单 |

## 四、关系强度分级

| 级别 | 可写关系 | 例子 |
|---|---|---|
| A1 | 正式认定 | 林忠诚为第六批国家级代表性传承人 |
| A2 | 官方个人页明确学艺/授徒 | 林炳光随余荣等学习、2001年开始授徒 |
| A3 | 政府或国家非遗平台明确职务 | 陈来发为南山队教练 |
| B1 | 队伍或机构公开教学合作 | 古帅青年英歌队辅导海外学员 |
| B2 | 受访者自述师承 | 需记录采访时间、地点、原话与授权 |
| C | 媒体概括、未署名口述 | 只作线索，不进入确定关系图 |

## 六、人物问答的推荐结构

回答一位人物时按五层组织：

1. **身份**：正式认定层级、项目、批次、序号；
2. **实践**：在哪个地区、队伍或平台活动；
3. **学艺**：开始年龄、教师或传承方式；
4. **传艺**：任教年份、授徒或课程平台；
5. **边界**：哪些字段未公开、哪些不能外推。

例如：

> 林炳光是第五批国家级非物质文化遗产代表性传承人，对应英歌（甲子英歌），官方序号05-2213。国家非遗个人页记载，他12岁开始随余荣等老艺人学习，2001年开始授徒，页面形成时已教授五十多名徒弟。这里的“五十多名”是官方档案当时的累计记录，不是当前在训人数；完整师承和弟子名册仍需项目申报档案或本人授权材料。
