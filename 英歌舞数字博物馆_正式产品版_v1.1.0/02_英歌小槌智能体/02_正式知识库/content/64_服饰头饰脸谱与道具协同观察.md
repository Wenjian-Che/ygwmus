# 服饰、头饰、脸谱与道具怎样共同工作

英歌造型不是把脸谱、服装和短槌分别拼在一起。视觉设计既要建立人物气质，也会影响舞者视线、散热、转头、槌路和队形安全。

## 四层观察

### 头面层

记录头冠轮廓、额部装饰、翎羽方向、固定方式和转头空间。翎羽在运动中会放大身体节奏，但也增加视觉宽度；判断队形间距时不能只看肩宽。

### 脸谱层

先描述底色、眉眼、鼻梁、额纹和左右对称，再讨论人物候选。颜色不能脱离队伍谱系单独解释。绘脸风格可能因师承、艺人和当次演出变化。

### 服装层

观察领口、护肩、袖口、腰带、前后襟、裤装和鞋。需要区分传统队服、近年新制演出服、舞台定制服装和IP化造型。

### 道具层

记录槌的长度、直径、重量、涂装、握位、是否成对以及实际接触方式。国家名录资料给出的尺寸属于通用项目说明，不能替代每支队伍的实物测量。

## 造型如何影响动作

- 高头饰和长翎羽要求更大的上方与侧方净空；
- 宽肩饰会改变双人交叉时的安全距离；
- 袖口和护腕可能影响握槌与翻槌；
- 腰带和前襟会影响深蹲、抬腿和转体；
- 鞋底材质会改变落脚摩擦；
- 浓重脸谱、汗水和灯光可能影响视线与散热。

因此“穿全套服饰排练”和便装训练承担不同任务，正式演出前需要进行服装条件下的适应。

## 为什么不能用颜色直接认角色

视觉识别应形成证据链：

1. 可见特征描述；
2. 已知队伍和演出时间；
3. 队列位置与行为职能；
4. 节目单或队伍角色表；
5. 绘脸者、教习或官方说明。

缺少后三层时，只能输出候选，不能把“红脸就是关胜、黑脸就是李逵”等简化说法当作确认。

## 服饰版本管理

队伍档案应为每套服饰建立：

```yaml
队伍:
服饰版本:
启用年份:
设计或制作人:
使用场景:
头饰:
脸谱方案:
上装与下装:
鞋:
英歌槌:
与旧版差异:
队伍确认人:
图片授权:
```

如果同一人物出现不同造型，先检查是否为不同年份、不同板式、女子队、少年队或舞台定制版本。

## 智能体看图回答顺序

1. 描述确定可见的元素；
2. 指出造型对动作和空间可能产生的影响；
3. 根据队伍信息给候选；
4. 明确不能从图片确认的部分；
5. 请求地点、队名、日期或节目单。
