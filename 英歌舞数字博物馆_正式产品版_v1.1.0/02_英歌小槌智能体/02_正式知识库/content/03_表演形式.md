# 英歌表演形式

## 基本构成

英歌以持双槌的群体舞者为视觉核心，结合锣鼓、槌击、吆喝、人物造型和动态队形。国家名录资料概括舞者多为双数，少则12人、多至108人，实际人数按队伍与场景变化。

来源：[中国非物质文化遗产网：潮阳英歌](https://www.ihchina.cn/project_details/12901.html)

## 身体动作

### 步型与重心

- 低重心和骑马蹲裆式步型；
- 提腿、横移、进退、跳步和转身；
- 不同板式的步幅、速度和停顿不同。

### 槌法

名录和地方资料记录舞槌、旋槌、击槌、背槌、过胯、抱槌勾脚等名称。它们必须精确到队伍和视频时间码，见 [[36_动作与步法词典]]。

### 身法

头、肩、躯干、腰胯与手腕共同形成动作，不能把英歌简化为只敲木棒。

## 声音

- 鼓控制速度和段落；
- 锣、钹、镲形成层次和声压；
- 槌击是舞者产生的集体节奏；
- 吆喝承担气势、回应和可能的动作信号；
- 螺号、唢呐等是否使用按队伍记录。

详见 [[39_锣鼓节奏与声音档案]]。

## 人物与领队

常见头槌、二槌、时迁、司鼓和群舞等称谓，但角色对应与职责没有统一版本。宋江不必然等于二槌或司鼓，时迁也不必然是总指挥。

## 队形

公开资料记录双龙出海、麦穗花、田螺圈、穿单龙、穿双龙、满天星等名称。同名可能不同形，详见 [[15_阵法与队形详解]]。

## 板式

慢、中、快板差异不仅是速度，还涉及槌长、击槌组合、锣鼓、动作质感与整体气势。潮阳内部就有三种板式，见 [[14_快板中板慢板详解]]。

## 传统结构

国家名录概括：

- 前棚：锣鼓和持槌英歌主体；
- 后棚：小戏和其他拿手节目。

现代舞台、城市巡游和短视频常对其压缩或重构，见 [[23_演出结构详解]]。

## 场景差异

| 场景 | 主要变化 |
|---|---|
| 社区巡游 | 长距离行进、多停演点、与地方仪式共享路线 |
| 城市巡游 | 多队伍调度、固定表演点和交通管理 |
| 舞台 | 人数缩减、正面构图、灯光扩声 |
| 校园 | 轻质器材、适龄强度和短组合 |
| 海外 | 时长压缩、翻译解说和运输限制 |

## 看表演的五个重点

1. 鼓点怎样启动与改变动作；
2. 槌击、提腿和重心是否同步；
3. 领队怎样给出信号；
4. 队伍如何在密集空间保持距离；
5. 队形怎样开合、穿插和收束。
