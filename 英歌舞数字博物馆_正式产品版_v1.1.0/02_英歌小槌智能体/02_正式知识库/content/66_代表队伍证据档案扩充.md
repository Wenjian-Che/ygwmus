# 代表队伍证据档案扩充

> [!important] 证据边界
> 本页主要依据汕头官方发布的2024年春节15支参演队伍介绍整理。它能证明“官方活动资料曾这样介绍该队”，但不等于队伍完整口述史，也不自动证明每个套路今天仍在使用。人数、年龄、活动经历等动态字段均绑定发布日期。

## 一、潮阳与汕头队伍

### 1. 潮阳棉北后溪英歌队

| 字段 | 已确认内容 |
|---|---|
| 成立 | 1948年 |
| 板式 | 潮阳中快板英歌代表之一 |
| 传承与基地 | 官方资料称队中有国、省、市、区级传承人；2012年训练基地获授“广东省非物质文化遗产传承基地” |
| 节奏 | 鼓点有慢、中、快三段，层次分明并可变调 |
| 身体特征 | 舞步稳健豪放、刚劲有力，强调武术中的刚柔关系 |
| 公开阵图 | 双龙出海、天罡朝圣、四打中街、双圈互逆、双金钱阵、四海欢腾、十字阵、八卦阵、满天星阵、众星拱月、群英欢庆 |
| 证据状态 | A级公开资料；具体阵图结构仍需图谱或视频逐阵核验 |

不要把“有慢、中、快鼓段”误答成“后溪兼有慢板、中板、快板三种独立板式”。前者是该资料对节奏组织的描述，后者需要额外的队伍口述或谱本支持。

### 2. 濠江联兴英歌队

| 字段 | 已确认内容 |
|---|---|
| 成立 | 2018年 |
| 组织特点 | 由热爱传统文化的青少年自发组建；“平均年龄二十多岁”仅限2024年资料时点 |
| 板式 | 中快板 |
| 槌法/套式 | 双花槌、七下槌、三十六步槌 |
| 阵法 | 双龙出海、猛虎下山、八卦阵 |

“三十六步槌”是该队公开套式名称，不应与“三十六人编制”混为一谈。

### 3. 潮阳西门女子英歌队

| 字段 | 已确认内容 |
|---|---|
| 地点 | 潮阳区文光街道西门社区 |
| 性别结构 | 女子英歌队 |
| 传统打法 | 老五下套 |
| 当代变化 | 对打、单打等套路 |
| 年代证据 | 2024年队伍介绍写“成立于1952年”；中国非遗网转载人民日报的完整报道明确写停滞多年后于2011年重新组建 |
| 结论 | 1952年是初建，2011年是社区帮助下的重新组建；两个年份属于不同事件 |

智能体回答成立时间时应写完整时间链：“1952年成立—长期停滞—2011年重新组建”，不可把2011年写成首次成立。详见《68_队伍资料冲突与时效性审计》。

### 4. 潮阳城南忠精英歌队

| 字段 | 已确认内容 |
|---|---|
| 成立 | 1996年 |
| 板式 | 公开资料称包含慢、中、快三种表演风格 |
| 当代探索 | 阵形、角色、服装方面均有创新尝试 |

该队是反驳“一个队只能归入一种板式”的直接个案，但不能据此推断所有队伍都兼有三种板式。

### 5. 潮阳文光岭东英歌队

| 字段 | 已确认内容 |
|---|---|
| 成立 | 官方资料表述为“解放初期” |
| 板式 | 潮阳慢板英歌代表之一 |
| 特色称谓 | 醉槌英歌舞 |
| 身体质感 | 似醉非醉、劲中转柔、悠然沉稳、慢中显势 |
| 动作解释 | 官方描述提到太极拳与舞蹈的混合观感 |

“醉槌”是风格称谓，不代表饮酒，也不能泛化为所有慢板英歌。“最古老”属于该活动资料的宣传性描述，不能直接转成已考定的历史排序。

### 6. 潮阳西胪英歌队

## 四、智能体回答模板

当用户问“某队怎么打”时，推荐按以下顺序回答：

1. 先说地区、成立或恢复时间；
2. 再说公开板式；
3. 分开列槌法/动作、锣鼓信号、阵形；
4. 标明哪些是该队个案，不能泛化；
5. 动态字段注明“截至某年官方资料”；
6. 若有冲突，展示冲突并说明待核方向。
