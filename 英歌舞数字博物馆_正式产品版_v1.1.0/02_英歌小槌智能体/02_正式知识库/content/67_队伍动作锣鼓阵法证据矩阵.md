# 队伍动作、锣鼓与阵法证据矩阵

## 后溪英歌队是什么板式，有哪些阵法

棉北后溪英歌队在2024年汕头官方队伍介绍中被列为潮阳中快板英歌代表之一。公开阵图包括双龙出海、天罡朝圣、四打中街、双圈互逆、双金钱阵、四海欢腾、十字阵、八卦阵、满天星阵、众星拱月、群英欢庆。阵名可以作为队伍证据回答，但精确站位和路线仍需阵图谱本或同步视频核验。

## 一、为什么要按队伍记录

英歌的槌名、阵名、节奏口令常由村落与队伍传承。名称相同不保证动作结构相同，名称不同也可能包含相似的空间机制。因此，本表只记录“某公开资料把某词与某队关联”，不建立未经田野核验的全国统一词典。

## 三、几个容易答错的词

### 1. “七下槌”“三十六槌”“三十六步槌”

它们来自不同队伍的公开命名，不能只因数字相近就合并：

- 联兴公开的是“七下槌”“三十六步槌”；
- 西胪公开的是“七下槌”以及2022年后增加“三十六槌”；
- 是否同源、同拍、同一动作单元，需同步视频和队伍口述才能判断。

### 2. “大战马”“四平马”“战马”

- 慈海把大战马、四平马列作基础；
- 甲子资料把时迁的姿态与南拳“战马”联系；
- 三者是否为同一训练术语、不同地方称谓或不同动作层级，不能凭字面等同。

### 3. 吹哨与锣鼓

桃园和古帅青年都公开提到“锣鼓控节奏、领队吹哨号令”。这说明听觉系统至少分为：

- 连续节拍层：锣鼓提供速度、重音与段落能量；
- 离散指令层：哨声提示起段、收段或转换；
- 视觉确认层：领队、头槌或前排身体动作帮助全队确认变化。

具体“几声哨对应哪一阵”仍属队伍内部信号，未经谱本或同步录像不能编造。

### 4. 阵名不是几何图答案

“双龙出海”“八卦阵”“满天星”等名称提供文化意象，却不能单靠名称复原站位。完整数字化至少需要：

- 队员编号与角色；
- 起始站位；
- 每拍移动方向和步数；
- 穿插、合拢、转向节点；
- 鼓点或哨声时间码；
- 场地宽度与安全间距。

## 四、用于智能体的回答规则

1. 用户问“英歌有哪些动作”时，先说动作因地区与队伍不同，再用甲子或具体队伍作例；
2. 用户问“哪声鼓对应哪动作”时，不给统一密码表，解释队伍信号词典不统一；
3. 阵名可列出，但不虚构路线图；
4. 同名动作跨队伍比较时，标记“同名未必同形”；
5. 对“学动作”类问题只给观察和文化解释，不替代传承人现场教学与安全指导。
