# 英歌角色与脸谱

## 角色体系不是统一演员表

许多英歌队借用梁山英雄，但人数、角色、脸谱、道具和领舞设置因队伍而异。不能用一张“108将对照表”解释所有英歌。

## 功能性角色

| 称谓 | 常见功能 | 边界 |
|---|---|---|
| 头槌 | 前排核心领舞 | 对应人物因队而异 |
| 二槌 | 重要领舞或配合角色 | 不必然是宋江 |
| 司鼓 | 以鼓点组织速度和段落 | 可能不在舞者队列 |
| 时迁 | 灵活穿行、引路或角色表演 | 道具和指挥功能不同 |
| 群舞 | 持槌完成动作和队形 | 人物对应可固定也可弱化 |
| 后棚角色 | 小戏、武术、花鼓等 | 只见于部分传统 |

## 水浒人物

李逵、关胜、林冲、武松、鲁智深、宋江、时迁等常见于公开介绍，但具体哪位担任头槌、脸谱颜色和兵器都要看队伍资料。

## 脸谱的作用

- 强化远距离辨识；
- 塑造人物个性；
- 统一队伍视觉；
- 与头冠、服装、道具和队列位置共同表达角色。

## 为什么不能套用统一色谱

英歌脸谱受戏曲影响，但还受村落师承、绘脸者、颜料、灯光和当代创新影响。可以描述颜色和构图，不能只凭红、黑、白直接认人。

## 可核实样本

### 甲子

汕尾市政府资料称武畔前24人各画不同花脸，眉、目、额、鼻、腮通过色调和线条差异塑造人物。

### 普宁南山

中国非遗网报道陈来发及南山队对燕青、阮小七等脸谱进行过色彩和图形创新，说明脸谱会随队伍实践变化。

详见 [[17_脸谱绘制技法详解]]。

## 图像识别规则

1. 先描述可见颜色、图案、头饰和道具；
2. 确认地点、队伍和活动；
3. 对照该队谱样和节目单；
4. 结合队列位置与动作；
5. 只有多项证据一致才给出角色候选；
6. 最终以队伍说明为准。

## 女子与儿童队伍

不要预设女子英歌脸谱更柔美，也不要把女性英雄叙事推广到全部女子队。儿童角色、器材和化妆还需监护、安全与影像授权。

## 本条可核验来源与边界

- A 级｜[中国非物质文化遗产网：普宁英歌项目页](https://www.ihchina.cn/project_details/12902.html)：用于核对普宁英歌的项目身份与公开项目说明；不能据此推出每支普宁队伍的角色谱完全相同。
- A 级｜[汕尾市人民政府：国家级非遗之甲子英歌](https://www.shanwei.gov.cn/slhwz/zjsw/content/post_1104466.html)：用于甲子武畔 24 张花脸及其眉、目、额、鼻、腮变化的个案；适用范围为该公开资料描述的甲子英歌，不外推至潮阳、普宁全部队伍。
- C 级｜具体队伍的节目单、谱样和绘脸者口述：用于确认某一角色与脸谱的对应关系，必须记录队伍、活动日期和说明人；未取得这些信息时只描述可见特征，不确认人物。
