# 英歌脸谱绘制：队伍样本与记录方法

## 基本认识

英歌脸谱用于塑造人物、强化远距离视觉和队伍风格。它受到戏曲脸谱影响，但不存在适用于全部地区的统一角色色谱或统一“五步法”。

## 已确认的甲子样本

汕尾市政府资料记载：

- 甲子英歌武畔前24人各画不同花脸；
- 24张脸谱互不相同；
- 眉、目、额、鼻、腮的造型和着色变化丰富；
- 通过浓淡繁简、曲直粗细的对比塑造人物；
- 与京剧、粤剧、西秦戏净角面谱有相似之处，但形成甲子自身特点。

来源：[汕尾市政府：国家级非遗之甲子英歌](https://www.shanwei.gov.cn/slhwz/zjsw/content/post_1104466.html)

## 已确认的普宁南山信息

中国非物质文化遗产网对陈来发的报道指出：

- 脸谱、服饰、队形共同表现故事和人物个性；
- 南山队对“燕青”“阮小七”等脸谱进行过创新；
- 创新包括色彩搭配和便于识别的人物图形；
- 服饰材料也会根据不同场景光线调整。

这说明脸谱会变化，并非数百年完全不动。

来源：[中国非物质文化遗产网：英歌舞今年为何“火出圈”](https://www.ihchina.cn/project_details/26532.html)

## 绘制过程如何记录

不同队伍可能采用不同顺序，调查时记录真实操作：

1. 清洁与皮肤防护；
2. 确认角色和参考谱样；
3. 底色或主要色块；
4. 眉、眼、额、鼻、腮等结构线；
5. 辅色、纹样和细节；
6. 头饰、胡须与服装整体检查；
7. 演出后的卸妆与皮肤观察。

这是一套**记录框架**，不是传统统一工序。

## 色彩怎样解释

可以说：

- “该脸谱以红色为主”；
- “该队绘脸者解释红色在此角色中表示……”；
- “这一构图与戏曲净角脸谱存在可比较之处”。

不应说：

- 红色在所有英歌中固定等于忠义；
- 黑色必然是李逵；
- 白色必然代表奸诈；
- 女性队伍一定使用更柔和的颜色；
- 颜色能独立证明队伍和年代。

## 材料与安全

- 记录颜料是否为人体面部使用产品；
- 演出前做小范围皮肤测试；
- 不共用直接接触眼口的工具；
- 眼周、破损皮肤和过敏史需特别谨慎；
- 未成年人由监护人知情；
- 演出后彻底卸妆并记录不良反应。

## 数字化对照

每张脸谱至少保存：

- 自然光正面、左右45度；
- 绘制过程关键步骤；
- 头冠和服装整体照；
- 色卡与相机信息；
- 同一角色不同年份；
- 同一角色不同绘脸者；
- 同一队伍传统版与舞台版。
