# 术语表与概念辨析

术语中的项目身份和人数等核心事实以 [[50_核心事实注册表]] 为准。

## 名称

| 术语 | 说明 | 使用提醒 |
|---|---|---|
| 英歌 | 国家级非遗名录采用的项目名称 | 正式写作首选 |
| 英歌舞 | 社会传播和日常使用中的常见名称 | 与“英歌”通常指同一传统 |
| 唱英歌、秧歌、鹰歌、鹦哥 | 历史或地方异称 | 不能仅凭同音推断词源 |
| 中华战舞 | 当代传播中的形象化称呼 | 是传播标签，不是传统分类术语 |

## 人员与角色

| 术语 | 基本含义 |
|---|---|
| 前棚 | 以持槌群舞为核心的主体段落；不同地方结构并不完全相同 |
| 后棚 | 传统演出中接续的小戏、武术或杂耍节目；当代常被省略 |
| 头槌、二槌 | 队列前部的核心舞者/领舞称谓，具体角色配置依队伍而异 |
| 时迁 | 常见的灵活调度角色，可持蛇、扇等道具穿行队伍 |
| 司鼓 | 以鼓点控制速度、段落和动作转换的人 |
| 棚头、教头、教练 | 队伍组织和传艺角色；称谓、权责因村落而异 |

## 动作、节奏与空间

| 术语 | 基本含义 | 观察重点 |
|---|---|---|
| 英歌槌 | 舞者双手持用的彩色短木棒 | 长短、粗细、重量因板式和队伍而异 |
| 舞槌/打槌 | 翻转、叩击、绕槌等动作总称 | 击点、方向、手腕线路 |
| 骑马蹲裆步 | 常见低重心步型 | 膝踝对线、重心稳定 |
| 快板/中板/慢板 | 按节奏、动作组合与整体气势形成的风格分类 | 不等同于固定行政区划 |
| 洗街、布田、旋槌等 | 名录资料记录的套路或动作称谓 | 同名动作在不同队伍中可能不同 |
| 阵法/队形 | 群体表演中的空间组合与变换 | 入口、出口、轴线、密度和方向 |

## 仪式与社会组织

| 术语 | 说明 |
|---|---|
| 游神/营老爷 | 潮汕民间信俗活动的常见称呼；英歌可参与巡游但二者不可等同 |
| 出队 | 队伍从驻地出发参加巡游或展演 |
| 起鼓/收鼓 | 一段表演的声音起止信号，也承担组织调度功能 |
| 村落传承 | 以社区、乡族和地方组织为基础的传承方式，不只是血缘家传 |
| 代表性传承人 | 非遗制度中的认定身份，不等于某传统的唯一权威 |

## 容易混淆的概念

### “水浒人物”不等于固定角色表

许多队伍借用梁山英雄叙事和脸谱，但人数、人物对应、领舞设置各有传统。不要用某一队伍的角色表覆盖全部英歌。

### “板式”不等于“流派”的全部

板式主要描述节奏速度、槌法组合和气势。一个地区可并存多种板式，一个板式也可能跨地区传播。地域、师承、套路、演出结构应共同描述。

### “傩文化关联”不等于“直接起源已证实”

驱邪纳吉、面部彩绘、节庆巡游等可用于比较研究，但相似元素不能单独证明单线起源。详见 [[21_傩文化渊源详解]] 与 [[30_常见争议与事实辨析]]。
