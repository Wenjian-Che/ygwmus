# 英歌鼓语、吆喝、哨声与听觉信号词典

## 一、声音不是一条轨道

英歌现场至少同时存在连续节拍、段落提示、离散号令、舞者自发声和环境声。智能体应先判断声音属于哪一层，再解释其可能功能。

| 信号类型 | 常见载体 | 可回答的功能 | 不能直接推出 |
|---|---|---|---|
| 基础脉冲 | 大鼓及锣钹循环 | 维持速度与共同周期 | 固定拍号 |
| 重音 | 鼓、锣、钹、槌击 | 标记发力或结构节点 | 必然对应某一动作 |
| 密度变化 | 连击、声部加入 | 提高紧张度或推进段落 | 一定发生加速 |
| 停顿/尾句 | 鼓句、全体停击 | 转段或收束候选 | 整场结束 |
| 领喊 | 头槌、二槌或其他领喊者 | 聚焦注意、提示动作转换 | 全国统一口令 |
| 群喊 | 全体舞者 | 回应、同步、气势 | 同一字词同一落拍 |
| 哨声 | 领队 | 离散号令 | 几声对应哪一阵 |
| 槌击声 | 自击或对击 | 舞者间校准、节奏层 | 现场鼓谱 |
| 铃声 | 服饰、草鞋或小铃鼓 | 运动反馈与音色层 | 所有队伍都有 |

## 二、甲子乐器与锣鼓口述

汕尾市政府公开资料记载甲子英歌使用1个大鼓、4面行锣、1个镲和2副钹，并用拟声描述一个保持一定速度循环的锣鼓点。

这段拟声只能作为检索标签，不能还原：

- 每种乐器的具体击法；
- 重音位置和强弱；
- 拍号、BPM或小节边界；
- 司鼓是否加入装饰音；
- 队伍在不同年代和场景中的变化。

记录时应同时保存传承人原读音、汉字转写、波形时间点和对应视频。

## 三、甲子八拍吆喝

### 已确认

- 每次动作变化前出现八拍吆喝；
- 前四拍由头槌“李逵”和二槌“杨志”领喊；
- 后四拍由舞者集体回应。

### 仍待采集

- 八拍是否与锣鼓循环完全重合；
- 每个音节的起点、延音和强弱；
- 领喊与群喊是否有重叠；
- 第八拍结束后动作立即变化还是另有准备拍；
- 不同动作是否使用相同吆喝。

### 回答边界

可回答“甲子公开资料记录了领喊—群答结构”；不可输出一张未经音视频核对的逐拍谱。

## 四、哨声与锣鼓怎样分工

桃园和古帅青年公开资料都使用“锣鼓掌握/掌控节奏、领队吹哨为号”的表述。由此可以确认两类信号并存：

- 锣鼓是持续的时间底层；
- 哨声是较突出的离散号令；
- 舞者还需结合领队身体、前后队员和场地判断方向。

“号令”可能涵盖起、停、转段、调位或变阵，但公开材料没有公布逐项映射。知识库只记录角色分工，不生成虚假哨声密码。

## 五、鼓点变快、变密和变响不是一回事

| 现象 | 测量方式 | 可能听感 |
|---|---|---|
| 速度加快 | 相邻基础拍间隔缩短 | 推进更快 |
| 密度增加 | 单位时间击打事件增多 | 更紧、更满 |
| 响度增强 | 峰值/RMS上升 | 更强、更近 |
| 声部增加 | 新乐器或群喊加入 | 更厚、更热烈 |
| 重音改变 | 周期内能量重新分布 | 方向感或段落感改变 |

手机自动增益会把强弱差异压平；剪辑软件变速会同时改变时长和音高；配乐覆盖会让“鼓点与动作同步”失去证据基础。

## 六、听觉事件标注词汇

```yaml
sound_event:
  channel: drum/gong/cymbal/clapper/call/whistle/bell/ambient
  onset:
  offset:
  original_label:
  normalized_function: pulse/accent/fill/pause/cue/response/closure/unknown
  intensity: measured/relative/unknown
  tempo_relation: stable/faster/slower/uncertain
  overlaps:
  linked_body_event:
  linked_formation_event:
  evidence_type:
  confidence:
```

`normalized_function` 是研究分类，不取代队伍自己的鼓语。若司鼓说“这一句叫××”，必须将原名放在 `original_label`。

## 七、录音与访谈的最小问题集

1. 这段鼓语由谁起、谁收？
2. 舞者听到什么才开始动？
3. 同一鼓句在排练、巡游和舞台是否变化？
4. 哨声、吆喝和鼓句冲突时以谁为准？
5. 转角、拥挤或人员掉拍时如何恢复？
6. 哪些鼓语可以公开，哪些只允许队内教学？
7. 传承人如何口述节拍，而不是研究者希望他如何数拍？

## 八、智能体的安全回答

- 不播放或生成“传统原谱”，除非谱例已获队伍授权并能追溯；
- 不把拟声词当作可执行鼓谱；
- 不把某支队伍的哨声规则推广到其他队；
- 不用现代电子鼓模拟结果证明传统鼓法；
- 回答具体音频时说明是否原声、是否连续、是否经过变速与降噪。
