# 接管说明

更新时间：2026-08-26

## 1. 项目定位

这是“英歌舞数字博物馆”的当前独立原型，不是旧站的升级分支。核心目标是把英歌的现场影像、互动叙事与可信知识组织为一个公众可理解、研究者可追溯的数字展馆。

核心三项：

1. 团队英歌舞视频
2. 木疙瘩 H5
3. 英歌小槌智能体

视频和 H5 素材尚未交付，因此页面只保留接入容器，不应伪装成已经开放。

## 2. 已确认的视觉方向

- 主色：螺青 `#3F503B`
- 强调色：珊瑚红 `#F04A3A`
- 辅色：琥棕 `#DE7622`
- 风格：冷静的数字展陈底色，结合朱砂动作能量、有限毛玻璃和英歌器物线性元素
- 毛玻璃只用于导航、控制面板、智能体浮层，不铺满所有内容
- 动效服务于入馆、转场、空间关系和内容理解，不作为装饰堆叠

Logo 开场是已确认资产，不要替换成简化版：SVG 描边与显影后归位至左上角，随后“英歌舞数字博物馆”文字以波浪节奏出现，再进入首页。

## 4. 技术结构

前台为无构建静态 HTML/CSS/JS：

- `web/app.js`：通用 GSAP 动效、页面转场、开场和智能体面板
- `web/styles.css`：首页、全局组件和响应式
- `web/museum-content.css`：内容馆页面
- `web/formation-scene.js`：Three.js 阵法
- `web/regions-map.js`：地区地图交互
- `web/vendor/`：本地 GSAP、ScrollTrigger、Three.js、TopoJSON

智能体：

- `backend/server.mjs`：HTTP API，默认端口 8787
- `web/data/`：运行时 chunks、词法索引和来源注册表
- `agent/`：RAG 配置、黄金答案、结构化知识、测试与维护说明

后台管理边界：

- 已迁入：`web/admin/` 独立可视化运营台，以及 `/api/admin/*` 管理 API。运营台包含总览、访客洞察、内容审核、项目策划和知识评测五个模块。
- 未迁入：旧工作区的 `admin.html`、`admin-feedback.html`、`admin-evaluation.html` 等管理页面。它们属于旧站工作区，不应直接复制进来。
- 安全：设置 `backend/.env` 的 `ADMIN_TOKEN` 后，所有管理 API（健康检查除外）要求 `Authorization: Bearer` 或 `X-Admin-Token`。

前台目前用 `http://127.0.0.1:8787/api/agent` 和 `/api/health`。部署前应改为环境可配置的同源 API 地址。

## 5. 已知问题与禁止回退

- 页面可运行，但内容深度仍不足；不要通过继续增加相似卡片解决。
- 各内容馆的大 Hero 与模板重复度偏高，下一轮应让每馆的首屏直接出现独有展品。
- “二级页面/二级展馆”是制作术语，应从所有观众可见文案中去除。
- 地域图必须区分“国家级项目地区、公开资料流传地、团队调研点”。整块行政区高亮不能暗示全域覆盖。
- 英歌小槌是导览 IP，不是传统脸谱、服饰或历史人物的证据。
- 阵法动画是结构示意，不替代具体队伍训练记录。
- 正式发布地图前必须使用合规标准地图。
- 不删除或重写已确认的 Logo 入馆动画。

## 6. 接管后的第一项工作

先把 `watch.html` 做成一条完整的“展品链路”样板：视频、字幕、章节时间点、拍摄信息、授权范围、来源、适用队伍和延伸阅读。视频未到之前可以完成数据结构与空状态，但不要虚构展品信息。

随后将同一证据组件推广到人物、阵法、声场和地域页。

## 7. 验收基线

- 视口：1920×1080、1440×900、768×1024、390×844
- 所有按钮必须可点击，页面无横向溢出
- 支持 `prefers-reduced-motion`
- 手机端不能隐藏全部全局导航而不给替代入口
- 内容结论必须标注来源、适用范围、证据类型和核校日期
- 不提交 `.env`、SQLite、日志、对话数据或本地绝对路径配置
